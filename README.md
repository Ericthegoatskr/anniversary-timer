# Anniversary Timer

A simple web-based timer that tracks and remembers anniversaries using your browser's `localStorage`.

## Opening Locally

1. Clone this repository or download the files.
2. Open `anniversary/index.html` directly in a modern web browser, or run a static file server and navigate to the page.

## Data Storage

All anniversaries you add are saved in your browser's `localStorage`. Clearing the browser data will remove the saved anniversaries.
